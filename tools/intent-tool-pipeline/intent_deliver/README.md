# Intent Deliveries

Place current user-supplied intent packages here when they are inputs to Workflow
A realization or Direct B intake. Preserve the supplied bytes and identify the
applicable file through the build request's `source_context` when a governed run
uses it.

This directory was named `handoffs/` before 2026-09-13. Historical run artifacts
retain that former path as captured provenance; new work uses `intent_deliver/`.
The separate `workspace/handoffs/` directory is historical migration provenance
and is not part of this rename.
