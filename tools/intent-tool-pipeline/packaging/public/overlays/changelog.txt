# ITP public seed history

## 2026-11-01 — ITP-PUBLIC-0.3.0-rc.1

**The initial public candidate publishes a curated, rebuildable ITP operational
seed from the current inventoried Nexus_AI working tree.** It preserves the nested
runtime layout and shared skills/role definitions, and replaces general Nexus_AI
root navigation with public installation, policy and provenance documents.

| Change | Compatibility and boundary |
| --- | --- |
| Public bundle/component VERSION `0.3.0-rc.1` | Original source VERSION and hashes are recorded in generated provenance; control revision remains a separate identity |
| Curated root docs, ignore policy, setup and distribution guides | No private workspace, unrelated research/experiments, checkpoints or archives are included |
| Explicit public inventory, pruned exact document policy and overlays | Source-only historical references remain disclosed; original component history/manifests are preserved |
| Two public-layout assertions replace Nexus-layout test assertions | Runtime assertions and operational procedure bytes remain unchanged |
| Deterministic builder and public profile tests | Fresh integrity, extraction/rebuild, boundary, CLI/procedure tests are executable acceptance checks; documentation is not their result record |

New runs inherit the authorized default control `1.2`; explicit `1.1` remains
compatible and new legacy `1.0` requires explicit selection. Existing runs are not
included or migrated. This is a candidate public assembly, not a clean upstream
commit, independent live-agent verification or new product release authorization.
Actual publication validation belongs in the external delivery record; this
preserved candidate document makes no unperformed-test claim. Historical component
changes are in [the retained tool history](tools/intent-tool-pipeline/CHANGELOG.md).
