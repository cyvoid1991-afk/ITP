transformation names, Git HEAD and dirty-state context. It contains no source
absolute paths or omitted private file names. These are publisher-supplied
integrity and source-mapping records, not an external attestation or signature.

and this document are authored overlays. VERSION is a documented public-only
override. The active distribution inventory/policy are explicitly replaced.

to the public boundary. Runtime, procedure and role bytes otherwise remain the

release archives and unrelated components are absent. Retained historical links
can point to source-only targets not provided by the public repository. Each
exception is identified in `DOCUMENT_REFERENCES.json`,
including referring-file hashes and reasons. Neither omitted evidence nor live
agent discovery/model execution is verified by a file hash check. No existing
run migration is performed. No license has been selected and no third-party
redistribution permission is granted.
